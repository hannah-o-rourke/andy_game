# Andrew's Standing Orders Scrum

A mobile-first gamified learning site for the Nelson City Council Standing Orders.

Open `index.html` directly, or deploy the repo root with GitHub Pages.

## Deploy on GitHub Pages

1. Push this folder to a GitHub repository.
2. In GitHub, open Settings > Pages.
3. Choose "Deploy from a branch".
4. Select `main` and `/root`.
5. Save.

The app stores Andrew's XP, streak, weak spots, and completed modules in browser local storage.
